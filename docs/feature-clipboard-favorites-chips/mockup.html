고정 칩 스트립 — 1줄

헤더 아래 1줄(≈38px). 넘으면 가로 스크롤(끝의 반 칩이 "더 있다"는 신호), 줄바꿈 없음. 개수 제한 없음, MRU 정렬: 마지막 붙여넣기한 항목이 맨앞으로 이동. 칩 탭 = 붙여넣기, ✕ = 핀 해제(항목은 최근 목록 복귀).

히스토리 목록

남은 높이를 전부 사용 — 핀 0개면 7행, 핀이 하나라도 있으면 항상 6행. 행 44px, 2줄 미리보기 + 상대 시간. ★ = 핀(→ 칩으로 이동), ✕ = 완전 삭제.

키보드 내비게이션

↑↓로 칩 → 히스토리 한 흐름 이동(기존 결합 인덱스 유지). 선택된 칩이 스크롤 밖이면 자동 스크롤. 선택은 라벤더 틴 + 링.

코드 단순화 부수 효과: MaxFavorites=10 상한과 "상한 도달 시 오래된 핀 밀어내기" 로직 모두 제거 — 칩 표시는 개수와 무관하고 MRU가 자연 정렬을 담당.
